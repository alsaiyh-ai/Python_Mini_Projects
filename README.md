# Python Mini Projects

A collection of small Python projects built while learning 
fundamentals with Elzero Web School — organized to show progression 
from basic string handling to conditional logic.

## Projects

1. Email Slicer — extracts username and domain from an email 
   using string slicing and .index()
2. Age Calculator — converts age into months, weeks, days, 
   hours, minutes, and seconds
3. Country Discount System — applies course discounts based on 
   user's country using if/elif/else and list membership (in)
